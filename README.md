# 📝 Progress Path - A Simple To-Do List App

Progress Path is a clean and minimal to-do list application built using pure **HTML**, **CSS**, and **JavaScript** — no frameworks or libraries needed!

---

## 🚀 Features

- ✅ Add up to 7 tasks per day
- 📅 Shows the current date with weekday and month
- 📊 Dynamic progress bar that updates with completed tasks
- 📌 Click tasks to mark them as complete/incomplete
- 💾 Saves your daily progress using `localStorage`
- 🎉 Motivational messages based on your progress
